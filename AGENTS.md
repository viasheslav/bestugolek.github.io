# Project architecture

This is a static Russian-language BESTUGOLĚK marketing website adapted from the supplied HTML attachment. There is no framework, package installation, build step, custom server, or application database.

- `public/index.html`: content, metadata, accessible landmarks, and Netlify Forms definition.
- `public/styles.css`: original brand design and responsive/accessibility refinements.
- `public/app.js`: mobile navigation, FAQ, product enquiry context, and URL-encoded form submission.
- `netlify.toml`: static publish directory and response headers.

Keep assets inside `public/`. Preserve Russian copy and the charcoal/green/kraft palette. Use progressive enhancement: content and real statistic values must remain visible without JavaScript. Honour reduced-motion preferences and keep keyboard navigation usable. Do not add animated counters or continuously running particle effects.

The `lead` form uses Netlify Forms with a hidden form-name field and honeypot. Every submitted field must appear in its static HTML definition. Only show success for an HTTP success response; keep user input on errors. Never store leads in browser storage or source files. The platform activation marker is generated by the Forms skill script.

Commercial claims and contact information originate in the attachment; do not invent replacements. No notification recipient has been configured by this implementation. Site name and description are defined in the HTML head using application-name and Open Graph metadata; do not add an og:image.
