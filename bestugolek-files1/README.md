# BESTUGOLĚK

Русскоязычный сайт производителя древесного угля, брикетов и оборудования. Основан на предоставленной HTML-странице, без зависимостей и этапа сборки.

## Технологии

Статический HTML, CSS и JavaScript. Netlify публикует `public/`; Netlify Forms принимает заявки формы `lead` с защитой honeypot. Успех отображается только после успешного ответа сервера, ошибки позволяют повторить отправку. Заявки доступны в разделе Forms проекта Netlify.

## Локальный просмотр

Запустите `python3 -m http.server 8080 --directory public` и откройте `http://localhost:8080`. Приём заявок работает на развёрнутом Netlify сайте; обычный локальный HTTP-сервер его не поддерживает.

Перед публикацией владелец должен проверить исходные коммерческие сведения: телефоны, адрес, цены, сертификаты и характеристики продукции. Они сохранены из предоставленного материала; отсутствующая часть адреса не выдумана.
